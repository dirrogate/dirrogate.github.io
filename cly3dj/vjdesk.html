Program recordings PROGRAM REC in the header

SIZE
The picture and sound that go to Twitch, recorded on this laptop as .mkv (H.264, the GPU's encoder when Chrome can use it; Opus sound), a steady 30 fps. Written as it goes into the browser's private storage, so a crash keeps all but the last 2 seconds; SAVE copies a take to a folder you pick (a crashed take: play it in VLC, or remux with ffmpeg -i in.mkv -c copy out.mkv). 1080p also draws the Program (and so Twitch / DirroTV) at 1080p while it records. About 3.6 GB an hour at 720p, 6.3 GB at 1080p.
